# 🏗️ Fênix EngCalculus Pro

O **Fênix EngCalculus Pro** é uma plataforma ERP integrada de engenharia desenvolvida para automatizar o levantamento de quantitativos, mapeamento de cargas e dimensionamento elétrico residencial com base estrita nas diretrizes da **NBR 5410** e tabelas dinâmicas da construção civil.

Este sistema foi projetado para centralizar as operações da **Fênix Engenharia**, permitindo a geração rápida de memórias de cálculo prontas para homologação em concessionárias de energia.

## ⚡ Funcionalidades Principais
- **Mapeamento de Cargas e Circuitos:** Lançamento individualizado de Iluminação, TUGs e TUEs.
- **Dimensionamento Automatizado NBR 5410:** Cálculo automático da seção nominal de cabos de cobre (Método B1) corrigidos por fatores de agrupamento.
- **Módulo de Construção Civil:** Levantamento quantitativo integrado por etapas de obra (Infraestrutura, Alvenaria e Acabamentos).
- **Salvamento e Exportação:** Memória de cálculo consolidada exportável em formato `.csv` para integração com Excel.

## 🛠️ Como Executar Localmente
Caso queira rodar o projeto na sua máquina:
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o aplicativo: `streamlit run app.py`
